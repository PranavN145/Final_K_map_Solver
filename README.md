# 🧩 K-Map Solver

## 📖 Short Description
K-Map Solver is an interactive web application that simplifies Boolean expressions using Karnaugh Maps. It provides a guided, step-by-step approach to solving K-Map problems by generating Gray Code-based maps, minimizing Boolean expressions, and visualizing the corresponding logic circuit. The project is designed as both a learning tool and a practical Boolean expression solver. :contentReference[oaicite:0]{index=0}

## ✨ Features
- Supports **2, 3, and 4-variable** K-Maps
- Interactive K-Map generation using Gray Code
- Automatic Canonical SOP generation
- Boolean expression minimization
- Logic circuit visualization
- Step-by-step guided solving process
- Input validation with hints and feedback
- Support for **Don't Care** conditions
- Clean and user-friendly interface :contentReference[oaicite:1]{index=1}

---

## ⚙️ The Process
1. Select the number of variables.
2. Enter the minterms (and Don't Care terms if required).
3. Generate the K-Map using Gray Code ordering.
4. Fill and group adjacent cells according to K-Map rules.
5. Generate the minimized Boolean expression.
6. Visualize the equivalent logic circuit. :contentReference[oaicite:2]{index=2}
